# ترنم شرق چابهار — واردات خودرو از امارات

وب‌سایت فارسی (RTL) با Next.js 16، React 19، Tailwind 4 و Motion؛ شامل کاتالوگ، ماشین‌حساب قیمت نهایی، فرم مشاوره و پنل مدیریت کامل.

## اجرا

```bash
npm install
cp .env.example .env.local   # و مقادیر را تنظیم کنید
npm run dev                  # http://localhost:3000
```

بدون `DATABASE_URL` پروژه با فایل `.data/db.json` و داده‌ی نمونه کار می‌کند (برای تست سریع).
برای PostgreSQL، `DATABASE_URL` را تنظیم کنید؛ جدول‌ها هنگام اولین اجرا خودکار ساخته می‌شوند.
برای درج خودروهای نمونه در PostgreSQL: `SEED_DEMO=true`.

## پنل مدیریت
آدرس `/admin` — نام کاربری و رمز از `ADMIN_USERNAME` و `ADMIN_PASSWORD`؛ حتماً `AUTH_SECRET` (حداقل ۳۲ کاراکتر) را در محیط production تنظیم کنید.
تصاویر آپلودی در `.data/uploads` (یا مسیر `UPLOAD_DIR`) ذخیره و از `/uploads/...` سرو می‌شوند.

## ساختار
- `src/lib/db` — ذخیره‌ساز PostgreSQL و JSON با یک رابط مشترک
- `src/lib/pricing.ts` — محاسبه‌ی قیمت نهایی (نرخ × قیمت درهم + هزینه‌ها)
- `src/proxy.ts` — محافظت از `/admin` (در Next 16 جایگزین middleware)
- `src/lib/importer.ts` — همگام‌سازی با Dubicars: خواندن صفحه‌ی جست‌وجو (`src/lib/dubicars.ts`)، دانلود عکس‌ها در `.data/uploads` و انتشار خودروها در کاتالوگ

## همگام‌سازی خودکار آگهی‌ها (Dubicars)

- همگام‌سازی **همه‌ی صفحه‌های جست‌وجو** را چرخه‌ای می‌گیرد: هر اجرا از `cursorPage` ذخیره‌شده ادامه می‌دهد و با پایان به ابتدای فهرست برمی‌گردد؛ شمار کل نتایج (مثلاً ۲۱٬۷۳۶) از خود صفحه خوانده می‌شود.
- اجرای زمان‌بندی‌شده: `npm run listings:worker` — هر `SYNC_INTERVAL_MINUTES` دقیقه (پیش‌فرض **۱۰**) یک دسته‌ی جدید؛ سرور Next باید در حال اجرا باشد.
- اجرای تک‌بار برای شروع/تکمیل چرخه: `npm run listings:sync` — دسته‌ها را پشت‌سرهم می‌زند تا همه‌ی صفحه‌ها تمام شود.
- هر دسته حداکثر `DUBICARS_TIME_BUDGET_MS` (پیش‌فرض ۱۵۰ ثانیه، سقف ۱۸۰) کار می‌کند و بین صفحه‌ها `DUBICARS_PAGE_DELAY_MS` (پیش‌فرض ۲۵۰۰ میلی‌ثانیه) مکث می‌کند تا Cloudflare مسدود نکند؛ اگر مسدود شد، همان صفحه در اجرای بعدی تکرار می‌شود.
- از پنل ادمین → «همگام‌سازی خودروها» می‌توانید یک دسته‌ی دستی بزنید (دکمه‌ی «اجرای آزمایشی» حداکثر ۳ صفحه را بدون ذخیره بررسی می‌کند) و پیشرفت چرخه (صفحه از کل) را ببینید.
- آدرس صفحه‌ی جست‌وجو، بودجه، مکث و تعداد تصاویر با `DUBICARS_SEARCH_URL`، `DUBICARS_TIME_BUDGET_MS`، `DUBICARS_PAGE_DELAY_MS`، `DUBICARS_PAGES` و `DUBICARS_IMAGES` قابل تنظیم است.
- خودروهای جدید بلافاصله منتشر می‌شوند؛ آگهی‌هایی که Dubicars برایشان قیمتی ثبت نکرده («قیمت را بپرسید») وارد نمی‌شوند. عکس‌ها با نام قطعی ذخیره می‌شوند و در اجرای بعدی دوباره دانلود نمی‌شوند؛ رکوردهای بدون تغییر به‌روزرسانی نمی‌شوند.
